METHOD 1

Production ZIP / Deployment

For enterprise rollouts, cloud deployments, or submission to the official Chrome Web Store.

  1. Download Extension ZIP:

    Click the download button above or grab dist/mahasetu-rpa-recorder-v1.0.0.zip.

  2. Unzip to Local Folder:

    Extract the ZIP archive into a permanent folder on your workstation.

  3. Configure Server Backend URL:

    In the extension popup or options, set your production backend URL (e.g. https://rpa.yourdomain.com). Click Test Ping to verify.

METHOD 2

Developer Mode (Unpacked)

Quickest method for local testing and customization during development.

  1. Open Chrome Extensions:

    Navigate to chrome://extensions in Google Chrome and enable Developer mode (top-right toggle).

  2. Load Unpacked:

    Click Load unpacked and select the extension directory:

    extension
  3. Ready to Record:

    The MahaSetu icon will appear in your Chrome toolbar.
